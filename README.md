# MaintainU Website Clone

A Next.js replication of the MaintainU website - a comprehensive maintenance services platform for the industrial sector.

## Features

- ✅ Fully responsive design
- ✅ Modern Next.js 15 with App Router
- ✅ TypeScript for type safety
- ✅ Tailwind CSS for styling
- ✅ Multiple pages (Home, About, Services, Contact, Works)
- ✅ Contact form with validation
- ✅ Mobile-friendly navigation

## Pages

- **Home** - Hero section, clients showcase, about preview, services overview
- **About** - Detailed company information and client list
- **Services** - Complete service offerings (Mechanical & Electrical)
- **Contact** - Contact form and company information
- **Works** - Portfolio of completed projects

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework:** Next.js 15
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Heroicons (via SVG)

## Customization

The color scheme can be adjusted in `globals.css`:

- Primary Green: `#5fcc6f`
- Primary Red: `#e85d75`
- Dark Blue: `#3d4f6d`

## Build for Production

```bash
npm run build
npm start
```
